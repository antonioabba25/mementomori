# Arquivo

Esta pasta guarda materiais históricos que ajudaram a orientar o produto, mas
que não fazem parte do runtime da aplicação.

## Conteúdo

- `visual-explorations/`: imagens, referências conceituais e protótipos
  gerados durante a exploração visual do wallpaper.
- `stitch-layout-brief.md`: brief usado para orientar uma rodada de refinamento
  visual/layout.

## Regra de Uso

Use estes arquivos como referência de contexto e direção estética. Não mova
assets exploratórios para `src` ou `public` sem uma necessidade concreta do
produto final.
